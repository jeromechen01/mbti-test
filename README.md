# 16 型人格测试 · 灵魂版

> 一个面向中文用户的 16 型人格测试网站。MBTI 心智 + 命理 八字 + 星座三盘融合，移动端优先，中英双语。

## 体验

直接打开：**`https://你的用户名.github.io/<repo-名>/`**

> 当前为小范围内测版本，欢迎反馈。

## 三档测试

| 档位 | 题量 | 输出 |
|---|---|---|
| **快速版** | 28 题 / 5 分钟 | 4 维 MBTI 类型 + 1 章核心信念预览 |
| **标准版** | 93 题 / 15 分钟 | 5 维（含 AT）+ 7 章灵魂深度报告 |
| **专业版** | 144 题 / 22 分钟 | 全 10 章 + 个人八字 / 太阳月亮上升透视 |

## 额外档位

- **关系匹配版**：双人 MBTI × 八字 × 星座 三盘合一 + 红绿灯风险信号 + 87 条相处建议
- **AI 顾问 · 小满**：30 天不限次的"汉学闺蜜"对话，针对你的 MBTI 给个性化建议

## 内测说明

- 测试码可向产品负责人索取
- 数据全部本地 localStorage 存储，不上服务器
- 文案完全原创，无任何抄袭

## 技术栈

- 单页应用（HTML + Alpine.js + Tailwind CSS via CDN）
- 0 后端依赖（纯静态文件，可双击运行）
- AI 对话通过 Cloudflare Workers 中转保护 API Key
